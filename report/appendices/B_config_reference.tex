\section{Configuration Hygiene Recommendations}
\begin{enumerate}[leftmargin=2em]
\item Never commit active production keys in plaintext repositories.
\item Regenerate shared keys for every new environment.
\item Validate JSON schema before process startup.
\item Separate environment profiles (dev/test/demo).
\item Add explicit key rotation and expiry metadata in future schema versions.
\end{enumerate}

\section{Config Validation Checklist}
\begin{itemize}[leftmargin=2em]
\item Client and server keys must match exactly.
\item Tunnel subnets should not overlap host physical subnet.
\item Server bind host should align with namespace/host execution mode.
\item MTU should account for overhead and path characteristics.
\end{itemize}
